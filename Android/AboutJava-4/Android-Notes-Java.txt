dp: density pixel  <-- for component size
sp: scalable pixel <-- for font size
https://developer.android.com/training/multiscreen/screendensities?hl=zh-tw

	android:layout_height="200dp"

	android:fontFamily="sans-serif"
	android:gravity="left|bottom"
	android:text="Hello World!"

(*) 圖片檔可以放入 drawable 目錄，但檔名必須都是小寫，開頭不可以是數字，只能是小寫英文與底線。

這個方法通常僅能修改原類別的名稱部分，更高一層的目錄則無法變更。
1) app >> kotlin+java >> ntut.s54007.original_class_name (refactor >> rename)
       >> ntut.s54007.new_class_name
   同時請 Android Studio 幫我們做相關的修改。


2) Gradle Scripts >> build.gradle.kts (Module :app)
   將原有舊類別的名稱，修改成新類別的名稱。

3) app >> res >> values >> strings.xml: app_name
